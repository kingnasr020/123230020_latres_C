# Responsi_123230020_IF-C

## Deskripsi Aplikasi
King Store merupakan aplikasi mobile sederhana berbasis Flutter yang dirancang sebagai simulasi toko online. Aplikasi ini memanfaatkan data produk dari API eksternal untuk menampilkan katalog barang secara dinamis.

Fitur utama yang tersedia pada aplikasi ini meliputi:
- Sistem login menggunakan username dan password
- Penyimpanan status login menggunakan SharedPreferences sehingga user tidak perlu login ulang saat aplikasi dibuka kembali
- Menampilkan daftar produk dari API eksternal
- Halaman detail produk dengan informasi lengkap
- Fitur menambahkan produk ke keranjang belanja
- Penyimpanan data cart secara lokal menggunakan Hive
- Data cart yang tersimpan berbeda untuk setiap username
- Halaman profile yang menampilkan informasi pengguna beserta tombol logout

## Teknologi yang Digunakan
Aplikasi ini dibangun menggunakan beberapa library dan tools berikut:
- Flutter
